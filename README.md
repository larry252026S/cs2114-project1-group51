# cs2114-project1-group51
We are building a coooking simulator where the user may combine ingredients to fulfill recipes to make food.
## How to Compile and Run

### Using Eclipse

1. Open Eclipse and import the project into your workspace.
2. Make sure the project is configured with a Java Runtime Environment (JRE).
3. In the Package Explorer, open `src` and then the `bossCooking` package.
4. Locate and open `Bosscooking.java`, which contains the `main` method.
5. Right-click `Bosscooking.java` and select **Run As → Java Application**.
6. The program will run in the Eclipse Console.
7. Follow the prompts in the Console to select ingredients and appliances and attempt to create a valid recipe.

### Running the Tests

1. Locate the test classes in the `bossCooking` package.
2. Right-click a test class and select **Run As → JUnit Test**.
3. Eclipse will display the test results in the JUnit panel.
4. A green test bar indicates that all tests passed.

### Program Requirements

- Java
- Eclipse IDE or another Java-compatible IDE
- JUnit 4 for running the provided test classes
